Note — ORGANIZING recall (2.7%): Stage 2 is trained only on event-flagged steps. The ORGANIZING class (SPLITTING + MERGING) has only 340 training samples vs 836 INTENSIFYING, creating a 2.5:1 imbalance. Despite oversampling, the model strongly favors INTENSIFYING recall because that class dominates signal in the Indian Ocean dataset. Future work: collect more ORGANIZING examples or apply stronger class-conditional focal weights.

🔍 Temporal Attention Weights

Interpretation: The TemporalAttention layer learns a monotonically increasing weight profile from t-7 (oldest, weight=0.028) to t-0 (most recent, weight=0.185) without explicit supervision. This emergent recency bias is physically consistent — the most recent cloud state is most predictive of near-term behavior. The weight ratio t-0/t-7 ≈ 6.6× confirms strong temporal locality.
